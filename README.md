# Alvaro Ortega Carregal - Portfolio

A modern, elegant, and responsive portfolio website showcasing my skills and experience as a Junior Web Developer.

## 🚀 Features

- **Responsive Design**: Fully responsive across all devices
- **Smooth Animations**: Elegant scroll animations and transitions
- **Modern UI**: Clean, professional design with sophisticated typography
- **SEO Optimized**: Proper meta tags and semantic HTML
- **Fast Loading**: Optimized performance with minimal dependencies

## 🛠️ Technologies Used

- HTML5
- CSS3 (with CSS Variables and modern features)
- Vanilla JavaScript
- Google Fonts (Playfair Display & Karla)

## 📦 Project Structure

```
portfolio/
├── index.html          # Main HTML file

├── script.js           # Interactive functionality
└── README.md           # Project documentation
```

## 🌐 Deployment

### Deploy to Vercel

1. Push this repository to GitHub
2. Go to [Vercel](https://vercel.com)
3. Click "New Project"
4. Import your GitHub repository
5. Click "Deploy"

### Deploy to Netlify

1. Push this repository to GitHub
2. Go to [Netlify](https://netlify.com)
3. Click "Add new site" → "Import an existing project"
4. Connect to GitHub and select your repository
5. Click "Deploy site"

## 📝 Customization

To customize this portfolio for your own use:

1. Update personal information in `index.html`
2. Modify colors in `styles.css` (CSS variables in `:root`)
3. Add your own projects and experiences
4. Replace contact information
